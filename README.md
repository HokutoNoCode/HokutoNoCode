#### 📖 Featured project: [FireReader](https://github.com/HokutoNoCode/FireReader)

An old **Amazon Fire HD 8 (2017)** turned into a **dedicated e-reader**:
unlocked entirely from Windows, LineageOS instead of Fire OS, and a home screen built only for reading,
with a cover library, **margin-free PDFs**, warm light and books over Wi-Fi. ~40 KB, no ads, no tracking.
